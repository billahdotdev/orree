# নতুন প্রোডাক্ট ও ল্যান্ডিং পেজ যোগ করার গাইড

> এক লাইনে: **প্রোডাক্ট যোগ করো → ক্যাম্পেইন যোগ করো → বিল্ড করো।** URL, ট্র্যাকিং,
> সাইটম্যাপ, Meta প্রিভিউ — সব নিজে থেকেই তৈরি হবে। কোনো রাউট হাতে লিখতে হবে না।

---

## দুটো পথ আছে

| | কখন ব্যবহার করবে | কোড লাগে? |
|---|---|---|
| **ক. `/admin` প্যানেল** | দ্রুত পরিবর্তন, দাম বদলানো, নতুন অফার পেজ | না |
| **খ. `siteData.js` এডিট** | স্থায়ী নতুন প্রোডাক্ট, ছবি সহ | হ্যাঁ (সামান্য) |

**গুরুত্বপূর্ণ:** `/admin` প্যানেলের পরিবর্তন ব্রাউজারে সেভ হয়, রিপোতে নয়। স্থায়ীভাবে
রাখতে `siteData.js`-এও লিখতে হবে। **আর prerendering (Meta লিংক প্রিভিউ) শুধু
`siteData.js` থেকেই কাজ করে** — কারণ ওটা বিল্ডের সময় চলে। তাই বিজ্ঞাপন চালানোর
প্রোডাক্ট সবসময় `siteData.js`-এ রাখো।

## পথ খ — পুরো ধাপ (এটাই সঠিক পদ্ধতি)

### ধাপ ১ — ছবি রাখো

`public/products/` ফোল্ডারে ছবি রাখো। নিয়ম:

- ফরম্যাট **`.webp`** (JPG-র চেয়ে ৩-৪ গুণ ছোট)
- মাপ **১০০০ × ১০০০ px** (বর্গাকার — গ্যালারি এই অনুপাতেই বসানো)
- ফাইলের সাইজ **২৫ KB-র নিচে** রাখার চেষ্টা করো
- নাম: `product-id.webp`, `product-id-2.webp`, `product-id-3.webp`

JPG/PNG থাকলে রূপান্তর করো:

```bash
# একটা ছবি
cwebp -q 80 -resize 1000 1000 photo.jpg -o public/products/new-product.webp

# পুরো ফোল্ডার
for f in raw/*.jpg; do
  cwebp -q 80 -resize 1000 1000 "$f" -o "public/products/$(basename "${f%.*}").webp"
done
```

> ছবি না থাকলেও সমস্যা নেই — `images: []` রাখলে ব্র্যান্ডেড প্লেসহোল্ডার দেখাবে,
> ভাঙা ছবি নয়। পরে ছবি এলে পাথ বসিয়ে দিলেই হবে।

### ধাপ ২ — `src/data/siteData.js` → `products` অ্যারেতে যোগ করো

```js
{
  // id একবার ঠিক করলে আর বদলাবে না। এটা কার্ট, শিটের পুরনো সারি,
  // আর Meta-র content_ids — সব জায়গায় ব্যবহার হয়।
  // বদলালে পুরনো অর্ডারের সাথে সংযোগ ছিঁড়ে যাবে।
  id: "mou-cha",
  title: "মধু চা",
  titleEn: "HONEY TEA",
  shortDesc: "এক লাইনে কেন কিনবে — কার্ডে আর Meta প্রিভিউতে এটাই দেখাবে।",
  ingredients: "মধু, আদা, দারুচিনি",
  benefits: [
    "প্রথম উপকারিতা",
    "দ্বিতীয় উপকারিতা",
    "তৃতীয় উপকারিতা",
  ],
  price: 650,
  compareAtPrice: 800,   // কাটা দাম। না থাকলে null
  currency: "৳",
  weight: "নেট ওজন ২৫০ গ্রাম",
  badge: "নতুন",         // "সিগনেচার" / "সেরা ভ্যালু" / null
  inStock: true,
  images: [
    "/products/mou-cha.webp",
    "/products/mou-cha-2.webp",
  ],
},
```

> ⚠️ **`compareAtPrice` কখনো বাড়িয়ে লিখো না।** কাটা দাম সবসময় আসল আলাদা দামের
> যোগফল হতে হবে। মিথ্যা ছাড় কাস্টমার নিজে হিসাব করে ধরে ফেলে, আর ভোক্তা অধিকার
> আইনেও সমস্যা।

### ধাপ ৩ — `campaigns` অ্যারেতে ল্যান্ডিং পেজ যোগ করো

**এই ধাপটাই URL তৈরি করে।** `slug` যা লিখবে, সেটাই ঠিকানা হবে।

```js
{
  id: "cmp-moucha",       // ভেতরের আইডি, শুধু অনন্য হলেই হলো
  slug: "moucha",         // → orree.bd/moucha  ← বিজ্ঞাপনে এই URL দেবে
  productId: "mou-cha",   // উপরের প্রোডাক্টের id-র সাথে হুবহু মিলতে হবে
  active: true,

  // নিচের সব ফিল্ড ফাঁকা রাখলে প্রোডাক্টের নিজের মান ব্যবহার হবে।
  // শুধু যেটা আলাদা করতে চাও, সেটাই লেখো।
  eyebrow: "",            // শিরোনামের উপরের ছোট লেখা
  headline: "",
  subheadline: "",
  badge: "",
  price: null,            // অফারের দাম (প্রোডাক্টের দামের বদলে)
  compareAtPrice: null,
  ctaText: "এখনই অর্ডার করুন",
  images: [],             // ক্যাম্পেইনের আলাদা ছবি
  benefits: [],
  offerEndsAt: null,      // "2026-09-15T23:59:59+06:00" দিলে কাউন্টডাউন দেখাবে
  showReviews: true,

  source: "lp-moucha",    // ⚠️ অনন্য রাখো — শিটে এটা দিয়েই চেনা যাবে
  metaTitle: "",          // ফাঁকা = প্রোডাক্টের নাম
  metaDescription: "",    // ফাঁকা = shortDesc
},
```

### ধাপ ৪ — বিল্ড করো

```bash
npm run build
```

আউটপুটে নতুন URL দেখতে পাবে:

```
prerender: 5 landing page(s) + sitemap (6 URLs)
  → https://orree.bd/candy
  → https://orree.bd/moucha      ← নতুন
```

## যা নিজে থেকেই হয়ে গেছে

এই দুটো অবজেক্ট লেখার পর নিচের সব কিছু **স্বয়ংক্রিয়** — আলাদা কিছু করতে হবে না:

| জিনিস | কোথায় | কীভাবে |
|---|---|---|
| রাউট `/moucha` | `App.jsx` | campaigns থেকে তৈরি হয় |
| `/lp/moucha` → `/moucha` রিডাইরেক্ট | `App.jsx` | এক প্রোডাক্ট = এক URL |
| canonical ট্যাগ | `usePageMeta` | `resolveCampaign` থেকে |
| স্ট্যাটিক HTML + OG ছবি | `scripts/prerender.mjs` | Meta প্রিভিউ ঠিক থাকে |
| `sitemap.xml` | prerender | নতুন URL যোগ হয় |
| ক্যাশ হেডার | prerender | `_headers`-এ যোগ হয় |
| ViewContent / AddToCart / Purchase | `tracker.js` | প্রোডাক্ট আইডি সহ |
| হোমপেজের প্রোডাক্ট কার্ড | `Products.jsx` | products অ্যারে থেকে |
| চেকআউটে ক্রস-সেল | `CrossSell.jsx` | products অ্যারে থেকে |
| Google Sheet-এ অর্ডার | `Code.gs` | নাম সহ |

## সাধারণ ভুল

**"নতুন URL 404 দেখাচ্ছে"**
`active: false` আছে, নয়তো `slug` ফাঁকা। অথবা বিল্ড চালাওনি।

**"পেজ খুলছে কিন্তু ভুল প্রোডাক্ট"**
`productId` প্রোডাক্টের `id`-র সাথে মিলছে না। বানান হুবহু মিলতে হবে।

**"Meta-তে লিংক শেয়ার করলে হোমপেজের ছবি আসছে"**
`npm run build` চালাওনি, অথবা শুধু `/admin` থেকে যোগ করেছ। prerendering
`siteData.js` থেকেই চলে। Meta-র কাছে পুরনো প্রিভিউ ক্যাশ থাকলে
[Sharing Debugger](https://developers.facebook.com/tools/debug/)-এ URL দিয়ে
**Scrape Again** চাপো।

**"শিটে কলাম এলোমেলো"**
নতুন কলাম যোগ করার পর পুরনো শিটের হেডার আপডেট হয় না। নতুন শিট বানাও,
নয়তো হেডার সারি হাতে ঠিক করো।

## প্রোডাক্ট সরাতে চাইলে

**সাময়িক (স্টক নেই):** `inStock: false` → কার্ড থাকবে, "স্টক নেই" দেখাবে।

**ল্যান্ডিং পেজ বন্ধ:** ক্যাম্পেইনে `active: false` → URL 404 হবে।
বিজ্ঞাপন চালু থাকলে করো না।

**পুরোপুরি মুছতে:** দুটো অ্যারে থেকেই সরাও। কিন্তু **id বদলিও না** —
শিটে ওই id দিয়ে পুরনো অর্ডার লেখা আছে।
